Qasid قاصد

Post to your own WhatsApp channel every day, from a folder on your own computer. No server, no account, no upload.

Read this first. Automating WhatsApp Web is against WhatsApp's Terms of Service, and accounts can be banned for it. There is no official API for personal Channels, so there is no safe alternative — only the choice of whether to accept the risk. Do not use a number you cannot afford to lose.

How it works

You keep a folder. Qasid reads it and posts it.

MyPosts/
  2026-09-04/
      1.jpg
      1.txt        ← the caption for 1.jpg
      2.jpg
      2.txt
  2026-09-05/
      1.jpg
  • One folder per date. Qasid posts today's and leaves the rest alone.
  • A picture and a .txt of the same name go out together.
  • A picture on its own is posted without a caption; a .txt on its own is posted as a message.
  • Start a filename with a time — 07-15 morning.jpg — to give that post its own hour.

What it does not do

  • It is not a website you sign into. It runs on your machine.
  • Your WhatsApp session never leaves your computer, and the page it opens is reachable only from that computer.
  • It will not send to lists of strangers, read your contacts, or post to groups. Your own material, your own channel.

Getting it

git clone https://github.com/farooqmusicai/qasid.git
cd qasid
python -m pip install -r requirements.txt
python -m playwright install chromium

Then run START.bat on Windows, or ./start.sh on macOS and Linux. Your browser opens at 127.0.0.1:8770, and the rest is on the page: choose the folder, add the channel, scan the QR code once.

One catch worth knowing

Qasid posts by driving a real browser, so the computer has to be switched on and awake when a post is due. It checks every 15 minutes and each channel has a window of a few hours, so a late start still goes out — but a sleeping computer posts nothing.
